# Ghost of Tsushima macOS Port

An unofficial community project documenting a Kegworks/Wine-based
setup for running Ghost of Tsushima on macOS.

## Requirements

- A compatible Mac running macOS
- A legally obtained copy of the game
- A compatible Kegworks/Wine configuration

## Setup

1. Review the configuration and installation scripts.
2. Install Rosetta 2 if required by your setup using
   `Install Rosetta.command`.
3. Configure the game using your existing Wine/Kegworks environment.

## Disclaimer

This project is unofficial and is not affiliated with the game's
publisher or developers. Commercial game files are not included.
Use only game files you are legally authorized to use.
